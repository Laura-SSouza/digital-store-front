# Digital Store

Projeto final de Front-end: uma loja virtual (Drip Store) feita com React,
com página inicial, listagem de produtos e visualização de produto.

> Em desenvolvimento.

## Tecnologias

- React
- Vite
- React Router
- ESLint

## Como rodar o projeto

Pré-requisito: Node.js 22.22 ou superior.

1. Clone este repositório
2. Instale as dependências: `npm install`
3. Inicie o servidor de desenvolvimento: `npm run dev`
4. Abra o endereço exibido no terminal (geralmente http://localhost:5173)
